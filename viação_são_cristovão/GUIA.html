1️⃣ Iniciando o Servidor

Abra um terminal/PowerShell na pasta server/ e execute:

node server.js

Você deve ver a mensagem:

Servidor rodando em http://localhost:3000

2️⃣ Primeiro Login

1

Abra login.html no navegador

2

Use email: admin@viacao.com e senha: 123456

3

Clique em LOGIN

4

Se correto, verá mensagem de sucesso

1

Clique em "Esqueceu sua senha?"

O código aparecerá na mensagem (ex: Demo: 123456)

Será redirecionado para página de reset

⚠️ AVISO DE SEGURANÇA

ESTE SISTEMA É APENAS PARA DEMONSTRAÇÃO!

Não use em produção sem implementar:

  • Criptografia de senhas (bcrypt)
  • Banco de dados real (MongoDB, PostgreSQL, etc.)
  • HTTPS obrigatório
  • Rate limiting contra força bruta
  • JWT para autenticação
  • Email real com nodemailer
  • Verificação de email
  • Logs de auditoria

🔧Solução de Problemas

❌ Erro: "Connection refused"

O servidor não está rodando. Abra um terminal na pasta server/ e execute:

node server.js

❌ Erro CORS ao enviar formulário

Verifique se o servidor está rodando. CORS está configurado para localhost:3000

❌ Código de recuperação não funciona

  • Verifique se copiar o código corretamente (sensível a maiúsculas/minúsculas)
  • Código expira em 15 minutos, solicite um novo se necessário
  • Verifique o console do navegador para mensagens de erro

❌ Senha não atualiza

  • Verifique permissões de arquivo em server/users.json
  • Abra console do servidor para ver mensagens de erro
  • Verifique se o JSON está válido

❌ Imagens de fundo não aparecem

Verifique se a pasta imagens/ existe e contém as fotos com os nomes corretos
